## 2. 真实链路架构与改动对比

### 2.1 AI 识别与自动分类链路
```
[相册选择/相机拍照] (mobile)
       │ POST /api/v1/items (skip_ai=false)
       ▼
[FastAPI 服务端] ──> 保存原图与缩略图 ──> 创建 ClothingItem (status=processing)
       │
       ▼ (enqueue_job "tag_item_image" -> Redis 6379)
[Redis 7.2.5] ──> TAGGING_QUEUE
       │
       ▼ (dequeue)
[arq Worker 进程] (app.workers.worker)
       │
       ├── 若配置 AI_BASE_URL ──> 调用外部视觉模型 ──> 提取 type/color ──> 写回 DB (status=ready)
       └── 若无 AI_BASE_URL ──> 捕获异常重试 (3次) ──> 降级写回 DB (status=error, ai_error=...)
                                                                │
                                                                ▼
                                                [移动端] 详情展示失败原因，支持手动补全与优先校正
```

### 2.2 定位、天气与 AI 搭配链路
```
[移动端打开搭配页]
       │
       ├── 优先尝试 expo-location 获取前台 GPS 经纬度
       └── 备选手选城市 (LocationCityModal: 北京/上海/广州/深圳/成都等)
              │
              ▼
[Open-Meteo 天气接口] ──> 获取当前实时温度、体感、湿度、天气状况 (如: 24°C cloudy)
       │
       ▼
[顶部天气胶囊更新] (📍 上海 24°C cloudy ▾)
       │
       ▼ 点击 "AI 帮我搭"
[POST /api/v1/outfits/suggest]
       │ 请求体携带:
       │ - occasion: 当前选中场合 (日常/工作/聚会/正式/运动)
       │ - weather_override: { temperature: 24, condition: "cloudy", ... }
       │ - time_of_day: "afternoon"
       ▼
[RecommendationService]
       │
       ├── 仅检索当前用户已拥有单品 (ownership=owned, is_archived=false)
       ├── 根据温度区间与场合过滤候选单品
       └── 调用文本模型生成搭配理由
              │
              ├── 模型可用 ──> 返回结构化搭配 ──> 自动填充进穿搭大图画布
              └── 模型未配置 ──> 返回明确 503 ──> 移动端展示透明提示条，保留手动滑动搭配
```

## 5. 配置指引与解除受阻步骤

当需要接入真实外部商业大模型（例如通义千问、DeepSeek、OpenAI 或各类兼容端点）时，只需在后端进行标准环境变量配置，**无需重新构建 APK**：

1. 打开 `wardrowbe/backend/.env`；
2. 填入有效的模型端点地址与密钥：
   ```env
   AI_INTERNAL_ENABLED=true
   AI_VISION_ENABLED=true
   AI_TEXT_ENABLED=true
   AI_BASE_URL=https://your-model-provider.com/v1
   AI_API_KEY=your-actual-api-key
   AI_VISION_MODEL=qwen-vl-max      # 或 gpt-4o 等视觉兼容模型
   AI_TEXT_MODEL=qwen-turbo        # 或 deepseek-chat 等文本模型
   ```
3. 在宿主机执行重启命令：
   ```bash
   BIND_HOST=0.0.0.0 bash wardrowbe/scripts/dev-local.sh stop
   BIND_HOST=0.0.0.0 bash wardrowbe/scripts/dev-local.sh start
   ```
4. 验证服务连通性：
   ```bash
   curl -s http://127.0.0.1:8000/api/v1/health/ai
   ```
   返回 `status: healthy` 即代表外部模型链路全通，所有图片上传将自动异步打标并写回衣物属性，搭配页“AI 帮我搭”将直接返回定制化穿搭推荐与搭配理由。
